# Yacht Brisa do Mar — Website

Website for **Yacht Brisa do Mar** — boat hire (yachts & jetskis) in Luanda, Angola.

**Tagline:** Explore com luxo nas ondas de Luanda

## How to publish free on GitHub Pages

1. Create a new repository on GitHub (e.g. `yachtbrisadomar` or `brisadomar-website`)
2. Upload **all** the files and folders in this project to the repository
3. Go to **Settings → Pages**
4. Under "Source", select the branch `main` (or `master`) and folder `/ (root)`
5. Save — your site will be live at:  
   `https://YOUR-USERNAME.github.io/REPO-NAME/`

## Structure

- `index.html` — Home page (Hero, Frota, Experiências, Contacto)
- `contact.html` — Contact page
- `css/` — Stylesheets
- `js/` — JavaScript
- `images/` — Place your boat photos here (replace the placeholder blocks)

## Next steps you can do

1. **Add real photos**  
   Put images of the boats in the `images/` folder and update the fleet cards in `index.html` (replace the `.placeholder-img` divs with real `<img>` tags).

2. **Update prices** (if you want to show them)  
   Edit the fleet section in `index.html`.

3. **Custom domain** (optional)  
   You can later point a domain like `brisadomar.ao` or `yachtbrisadomar.com` to GitHub Pages for free.
